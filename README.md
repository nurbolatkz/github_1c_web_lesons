# 1C + React Lessons

This repository is a GitHub Pages lesson site for building repeatable projects with:

- React frontend
- 1C backend
- Python bridge services between React and 1C
- Codex CLI, Claude Code, and GitHub CLI assisted development

## Local Structure

```text
.
├── _config.yml
├── index.md
├── project-overview.md
└── lessons/
    ├── 00-course-plan.md
    ├── 01-toolchain-installation.md
    ├── 02-standard-project-architecture.md
    └── 03-first-project-workflow.md
```

## Publish With GitHub Pages

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to `Settings -> Pages`.
4. Set source to `Deploy from a branch`.
5. Select the main branch and the repository root.
6. Save.

The site will be available at:

```text
https://<github-user>.github.io/<repository-name>/
```
